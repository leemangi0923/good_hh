# good_hh
최고의 휴리스틱을 찾게 도와줄 수 있는 최휴 탐지기

[최휴 탐색기 열기](https://leemangi0923.github.io/good_hh/)

## 웹사이트 게시

GitHub 저장소의 **Settings → Pages**에서 다음과 같이 설정합니다.

- Source: **Deploy from a branch**
- Branch: **main**, 폴더: **/(root)**

저장 후 배포가 완료되면 위 링크에서 탐색기를 사용할 수 있습니다.
기본 페이지는 `index.html`이며 별도의 빌드 과정은 필요하지 않습니다.

## 버전 관리

최초 표시 버전은 **v6.0.0**입니다. 화면 상단의 버전 옆에는 해당 버전의 업데이트 일시를 한국 시간(KST), 연·월·일·시·분까지 표시합니다.

- 작은 버그 수정: 세 번째 숫자 증가 (예: v6.0.0 → v6.0.1)
- 일반 기능 업데이트: 두 번째 숫자 증가, 세 번째 숫자 초기화 (예: v6.0.1 → v6.1.0)
- 대규모 업데이트: 첫 번째 숫자 증가, 나머지 초기화 (예: v6.1.0 → v7.0.0)
