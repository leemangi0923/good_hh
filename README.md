# good_hh
최고의 휴리스틱을 찾게 도와줄 수 있는 최휴 탐지기

[최휴 탐색기 열기](https://leemangi0923.github.io/good_hh/)

## 웹사이트 게시

GitHub 저장소의 **Settings → Pages**에서 다음과 같이 설정합니다.

- Source: **Deploy from a branch**
- Branch: **main**, 폴더: **/(root)**

저장 후 배포가 완료되면 위 링크에서 탐색기를 사용할 수 있습니다.
기본 페이지는 `index.html`이며 별도의 빌드 과정은 필요하지 않습니다.
